# 🐰 taco 派對兔 YT 播放器

**https://sdfvgv1994-bot.github.io/taco-party/**

派對兔風格的 YouTube 音樂播放器，**積木架構**：每個功能都是一塊可以開關的積木。
手機打開網址就能用，不用開電腦、不用連同一個 Wi-Fi；加到主畫面就像一個 App。

- 貼上 YouTube 影片、Shorts、分享連結、YouTube Music 或**播放清單**連結（可以一次貼很多個），播放清單會展開成一首首歌
- 同一首不會重複加；歌名自動抓（抓不到就等開始播放時從播放器拿）
- 上傳者不開放嵌入、已刪除的歌會標成「無法播放」，自動換歌時跳過；整份清單都不能播就停下來，不會一直重試
- 上一首／下一首、🔀 隨機、🔁 全部循環／🔂 單曲循環／不循環、拖曳進度
- ✂️ 進歌點／切歌點：每首歌可以設定從第幾秒開始、第幾秒自動切歌
- 🌙 睡眠定時器：15／30／45／60 分鐘後自動暫停
- 💾 收藏歌單：把待播清單存成好幾份有名字的歌單
- 🧱 積木中心：每塊積木都可以即時開或關
- 🐰 派對房：**準備中**，下一版改用 Firebase 即時同步（朋友在哪都能一起點歌）

## 說明
- 只用 YouTube 官方的嵌入播放器播放，**不下載任何影音**，所以需要網路
- 歌單存在這台裝置的瀏覽器裡
- 「封面模式」只是用封面蓋住影片畫面，影片照常在下面播放（不會比較省電或省流量）
- 這個專案是從 `yt_party_player`（要在家用電腦跑 Python 伺服器的版本）改過來的：
  原本交給電腦做的事（解析連結、抓歌單、抓歌名）全部改在手機瀏覽器裡做，
  而且放在有 https 的正式網址上，YouTube 比較不會拒絕播放

## 程式
| 檔案 | 內容 |
|---|---|
| `index.html`、`styles.css` | 畫面骨架與樣式 |
| `app.js` | 組裝積木、底部分頁、迷你播放條、安裝提示 |
| `core/yt-core.js` | 規則：解析 YouTube 連結、加歌不重複、下一首是哪首（跳過播不了的歌）；不碰畫面，測試也用它 |
| `core/yt-api.js` | 載入 YouTube 官方播放器、讀播放清單、問歌名（oEmbed） |
| `core/store.js`、`core/event-bus.js`、`core/block-registry.js` | 狀態存檔、事件、積木開關 |
| `blocks/*.js` | 六塊積木：播放器、歌單匯入、待播清單、派對房、睡眠定時器、進歌／切歌點 |
| `sw.js`、`manifest.webmanifest`、`*.png`、`icon.svg` | 裝到手機桌面用的 App 檔案 |
| `tests/test_app.py` | 測試（`pytest`，需要 node） |

main 有改動時，GitHub Actions「網站上線」會先跑測試，通過才更新網站。
第一次要在 GitHub 的 **Settings → Pages → Source** 選 **GitHub Actions**。
